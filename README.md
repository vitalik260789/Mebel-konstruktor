# Мебель-Конструктор

Веб-приложение для проектирования корпусной мебели прямо в браузере, без установки.

- **Шаблоны:** тумба прикроватная, комод, шкаф, стеллаж, тумба с дверцами. Все размеры параметрические.
- **3D-вид** с прозрачностью, разнесением деталей и показом отверстий.
- **Деталировка:** чистовые и пильные размеры, кромка по каждому торцу (меняется кликом), свои детали вручную.
- **Присадка автоматически:** конфирматы 7×50, петли (чашка Ø35 и планка), полкодержатели, ручки, короба ящиков.
- **Чертежи деталей:** размеры, координаты отверстий от угла 0,0, таблица присадки, добавление своих отверстий.
- **Раскрой:** гильотинная раскладка на листы с пропилом и обзолом, по материалам.
- **Фурнитура и расход:** конфирматы, петли, направляющие, ручки, кромка в метрах, листы плиты.
- **Экспорт:** CSV для распиловочного центра (открывается в Excel), DXF для ЧПУ, печать и PDF, файл проекта.
- **«Поделиться»:** ссылка содержит весь проект, друг откроет у себя копию и сможет работать.

Проект автоматически сохраняется в браузере.

## Запуск локально

Это статический сайт: `index.html`, `app.js`, `core.js`, `style.css` и `vendor/` (three.js).
Нужен любой локальный веб-сервер, например:

```
python -m http.server 8000
```

Затем открой http://localhost:8000

## Система координат

X — слева направо, Y — вверх от пола, Z — от задней стенки к фронту.
На чертеже деталь показана со стороны пласти A, отсчёт от левого нижнего угла.
Торцы: Д1 — нижний, Д2 — верхний, Ш1 — левый, Ш2 — правый.
